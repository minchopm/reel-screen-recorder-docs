# Reel: Screen Recorder Face Cam — quick start

## Goal

Complete one small, verifiable task before using the workflow for a larger project.

## Before you begin

Use the current product from the official source. Check its device requirements and entitlements; a free download does not necessarily mean every operation is free. The feature table records product-specific limits.

## Steps

1. Choose one task to demonstrate and prepare a sample account or non-sensitive screen. Close notifications that could interrupt the recording.

2. Open Reel and select the recording quality and orientation for your destination. Start with 1080p if you do not need native pixels.

3. Enable the camera if you want a presenter overlay. Place it away from the controls you will touch. Check lighting and background treatment.

4. Allow the relevant camera, microphone and screen-recording permissions when prompted. On iPhone/iPad, use the screen broadcast flow presented by the app.

5. Set microphone and app-audio levels separately. Record a ten-second test that includes speech, app sound and a screen change.

6. Stop and play the saved MP4 with headphones. Confirm that the camera, full demonstration and both audio sources are present.

7. Record the full walkthrough, then inspect the beginning and end before sharing the file.

## Verify the result

Return to the saved output or record rather than relying only on the preview. Check the specific items described in the steps above. If the result differs, keep the original input and reproduce the issue with a small, non-sensitive example.
